10.7 Verdadero o falso

  1. Para hacer referencia a una ubicación o elemento específico en un arreglo, especificamos el nombre del arreglo y el valor del elemento.
    Falso. Se especifica el nombre del arreglo y el índice (número de posición) del elemento, no su valor.
  2. La declaración de una variable reserva espacio para un arreglo.
    Falso. Declarar una variable no crea el arreglo. Hay que crearlo con new Array( n ) o con un literal como [ 1, 2, 3 ], que es lo que realmente reserva el espacio.
  3. Para indicar que deben reservarse 100 ubicaciones para el arreglo entero p, el programador debe escribir p[ 100 ];
    Falso. Esa instrucción no es una declaración válida. Lo correcto es var p = new Array( 100 );
  4. Un programa que inicializa los elementos de un arreglo de 15 elementos en cero debe contener cuando menos una instrucción for.
    Falso. Puede usarse una lista de inicialización ([ 0, 0, 0, ... ]) o asignar cada elemento por separado.
  5. Un programa que calcula el total de los elementos de un arreglo bidimensional debe contener instrucciones for anidadas.
    Falso. Se puede hacer sin for anidados, por ejemplo sumando cada elemento con instrucciones individuales o usando métodos como reduce sobre cada fila. Los for anidados son lo más común, pero no son obligatorios.
