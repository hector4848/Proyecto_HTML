Ejercicios de autoevaluación

2.1 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué.

a) Una lista ordenada no puede anidarse dentro de una lista desordenada. Falso. Una lista ordenada puede anidarse dentro de una lista desordenada y viceversa.

b) El elemento br representa un salto de línea. Verdadero.

c) Los hipervínculos se denotan mediante elementos link. Falso. Los hipervínculos se denotan mediante elementos a.

d) La anchura de todas las celdas de datos en una tabla debe ser igual. Falso. Puede especificar la anchura de cualquier columna, ya sea en píxeles o como un porcentaje de la anchura de la tabla.

e) Estamos limitados a un máximo de cinco vínculos internos por página. Falso. Puede tener un número ilimitado de vínculos internos.

2.2 Complete las siguientes oraciones:

a) El elemento hr inserta una regla horizontal.

b) Para marcar un superíndice se utiliza el elemento sup y para marcar un subíndice se utiliza el elemento sub.

c) El elemento de encabezado menos importante es h6 y el elemento h1.

d) El elemento ul marca una lista desordenada.

e) El elemento p marca un párrafo.

f) El atributo type="reset" en un elemento input inserta un botón que, cuando se presiona, restablece el contenido del formulario.

g) El elemento tr marca una fila de una tabla.

h) Los asteriscos (*) se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.
