Ejercicio 6.13 - Ecuación y = ax³ + 7

Son correctas:

  • a) y = a * x * x * x + 7;
  • d) y = ( a * x ) * x * x + 7;
  • e) y = a * ( x * x * x ) + 7;

Son incorrectas:

  • b) y = a * x * x * ( x + 7 ); — calcula ax³ + 7ax², porque el 7 se suma dentro del paréntesis antes de multiplicar.
  • c) y = ( a * x ) * x * ( x + 7 ); — mismo error que en b).
  • f) y = a * x * ( x * x + 7 ); — calcula ax³ + 7ax, porque el 7 queda multiplicado por a y x.
