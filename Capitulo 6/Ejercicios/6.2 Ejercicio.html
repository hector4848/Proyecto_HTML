Ejercicio 6.2 - Verdadero o falso

  1. Falso. Los comentarios no se imprimen; el intérprete simplemente los ignora. Sirven para documentar el código.
  2. Falso. JavaScript distingue entre mayúsculas y minúsculas, por lo que numero y NuMeRo son variables distintas.
  3. Verdadero. El operador residuo (%) solo se usa con operandos numéricos.
  4. Falso. *, / y % tienen el mismo nivel de precedencia, pero es mayor que el de + y -.
  5. Falso. parseInt convierte una cadena en un entero, no al revés.
