(Problema del else suelto) Determine la salida de cada uno de los siguientes segmentos de código, cuando x es 9 y y es 11, y cuando x es 11 y y es 9. El intérprete de JavaScript siempre asocia un else con el if anterior, a menos que se le indique de otra forma mediante la colocación de llaves. 

  1. if ( x < 10 )
   if ( y > 10 )
      document.writeln( "<p>*****</p>" );
   else
      document.writeln( "<p>#####</p>" );
document.writeln( "<p>$$$$$</p>" );
    El else pertenece al if ( y > 10 ), que es el más cercano. La última instrucción no está dentro de ningún if, así que siempre se ejecuta. 
    Con x = 9 y y = 11:
*****
$$$$$

Con x = 11 y y = 9:
$$$$$
  2. if ( x < 10 )
{
   if ( y > 10 )
      document.writeln( "<p>*****</p>" );
}
else
{
   document.writeln( "<p>#####</p>" );
   document.writeln( "<p>$$$$$</p>" );
}
    Las llaves hacen que el else pertenezca al primer if ( x < 10 ). 
    Con x = 9 y y = 11:
*****

Con x = 11 y y = 9:
#####
$$$$$
