7.9

Identifique y corrija los errores en cada uno de los siguientes segmentos de código. [Nota: puede haber más de un error en cada fragmento; a menos que haya declaraciones presentes, suponga que todas las variables están declaradas e inicializadas correctamente]. 

  1. if ( edad >= 65 );
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65 )";
    Error 1: el ; después del paréntesis derecho de la condición del if. Deja el if con una instrucción vacía, por lo que el else queda sin su if y se produce un error de sintaxis.
    Error 2: en el else, las comillas y el paréntesis están mal colocados.
    Corrección: quitar el punto y coma y cerrar la cadena antes del paréntesis. 
    if ( edad >= 65 )
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65" );
  2. var x = 1, total;

while ( x <= 10 )
{
   total += x;
   ++x;
}
    Error: la variable total no se inicializó. Su valor es undefined, así que el resultado de la suma sería NaN.
    Corrección: inicializar total en 0. 
    var x = 1, total = 0;

while ( x <= 10 )
{
   total += x;
   ++x;
}
  3. var x = 1;
var total = 0;

while ( x <= 100 )
   total += x;
   ++x;
    Error: faltan las llaves que encierran el cuerpo del while. Sin ellas, solo total += x; forma parte del ciclo, y ++x; queda fuera. Como x nunca cambia dentro del ciclo, se crea un ciclo infinito.
    Corrección: encerrar ambas instrucciones entre llaves. 
    var x = 1;
var total = 0;

while ( x <= 100 )
{
   total += x;
   ++x;
}
  4. var y = 5;

while ( y > 0 )
{
   document.writeln( y );
   ++y;
}
    Error: se usa el operador de incremento (++y) en lugar del de decremento. Como y empieza en 5 y solo aumenta, la condición y > 0 nunca se vuelve falsa y se crea un ciclo infinito.
    Corrección: usar --y. 
    var y = 5;

while ( y > 0 )
{
   document.writeln( y );
   --y;
}
