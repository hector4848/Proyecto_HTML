Ejercicio 8.12 - ¿Qué imprime cada instrucción?

Valores: i = 1, j = 2, k = 3, m = 2.

  1. i == 1 → true. Los paréntesis no son necesarios.
  2. j == 3 → false. No son necesarios.
  3. i >= 1 && j < 4 → true && true → true. No son necesarios.
  4. m <= 99 && k < m → true && false → false. No son necesarios.
  5. j >= i || k == m → true || false → true. No son necesarios.
  6. k + m < j || 3 - j >= k → 5 < 2 es false y 1 >= 3 es false → false. No son necesarios, porque la aritmética tiene mayor precedencia que la comparación, y esta que ||.
  7. !( k > m ) → !( true ) → false. Aquí sí son necesarios: sin ellos, !k > m aplicaría ! solo a k, dando una expresión distinta.
