Ejercicio 8.2 - Instrucciones de JavaScript

a) Suma de los enteros impares del 1 al 99 (for)

suma = 0;
for ( cuenta = 1; cuenta <= 99; cuenta += 2 )
   suma += cuenta;

b) 2.5 elevado a la potencia de 3

resultado = Math.pow( 2.5, 3 );

c) Enteros del 1 al 20 con while, cinco por línea

x = 1;
document.write( "<p>" );
while ( x <= 20 )
{
   document.write( x + " " );
   if ( x % 5 == 0 && x < 20 )
      document.write( "</p><p>" );
   x++;
}
document.write( "</p>" );

d) Lo mismo con for

document.write( "<p>" );
for ( x = 1; x <= 20; x++ )
{
   document.write( x + " " );
   if ( x % 5 == 0 && x < 20 )
      document.write( "</p><p>" );
}
document.write( "</p>" );
