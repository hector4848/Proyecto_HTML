Ejercicio 8.3 - Encuentre el error

a)

Error: hay un punto y coma después de la condición del while y falta la llave de apertura {. El ; deja el cuerpo del ciclo vacío, por lo que x nunca cambia y el ciclo es infinito.

Corrección:

x = 1;
while ( x <= 10 )
{
   ++x;
}

b)

Error: falta break en el case 1. Si n es 1, se imprime "El número es 1" y la ejecución continúa en el case 2, imprimiendo también "El número es 2".

Corrección:

switch ( n )
{
   case 1:
      document.writeln( "El n&uacute;mero es 1" );
      break;
   case 2:
      document.writeln( "El n&uacute;mero es 2" );
      break;
   default:
      document.writeln( "El n&uacute;mero no es 1 ni 2" );
      break;
}

c)

Error: la condición n < 10 termina el ciclo cuando n vale 10, así que solo se imprimen los valores del 1 al 9. Para incluir el 10 se debe usar el operador <=.

Corrección:

n = 1;
while ( n <= 10 )
   document.writeln( n++ );
