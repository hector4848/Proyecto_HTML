Ejercicio 8.4 - Encuentre el error

a) For ( x = 100, x >= 1, ++x ) document.writeln( x );

Errores:

  • For está en mayúscula; JavaScript distingue mayúsculas y minúsculas, debe ser for.
  • Las expresiones del encabezado se separan con punto y coma (;), no con comas.
  • ++x incrementa el contador, pero la condición x >= 1 espera que vaya bajando desde 100; el ciclo sería infinito. Hay que usar --x.

Corrección:

for ( x = 100; x >= 1; --x )
   document.writeln( x );

b) switch ( valor % 2 )

Error: falta break en el case 0. Con un entero par se imprimiría "Entero par" y la ejecución continuaría en el case 1, imprimiendo también "Entero impar".

Corrección:

switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
      break;
   case 1:
      document.writeln( "Entero impar" );
      break;
}

c) for ( x = 19; x >= 1; x += 2 )

Error: x += 2 aumenta el contador, así que nunca llega a ser menor que 1 y el ciclo es infinito. Para ir de 19 a 1 de dos en dos se debe restar.

Corrección:

for ( x = 19; x >= 1; x -= 2 )
   document.writeln( x );

d) Enteros pares del 2 al 100 con do...while

Errores:

  • While está en mayúscula; debe ser while.
  • La condición contador < 100 termina el ciclo antes de imprimir el 100; debe ser contador <= 100.

Corrección:

contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} while ( contador <= 100 );
