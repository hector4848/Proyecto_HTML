9.30 ¿Qué hace la siguiente función?

function misterio( a, b )
{
   if ( b == 1 )
      return a;
   else
      return a + misterio( a, b - 1 );
}

Respuesta: la función calcula el producto de a por b (a * b) mediante sumas repetidas, de forma recursiva. Suma a un total de b veces. Por ejemplo, misterio(3, 4) = 3 + 3 + 3 + 3 = 12.
