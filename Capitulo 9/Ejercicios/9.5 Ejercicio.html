Ejercicios de autoevaluación

9.5
Localice el error en cada uno de los siguientes segmentos de programa y explique cómo corregirlo: 
  1. method g()
{
    document.writeln( "Dentro del m&eacute;todo g" );
}
    Error: method no es la palabra clave que se utiliza para comenzar la definición de una función.
    Corrección: cambiar method a function. 
  2. // Esta función debe devolver la suma de sus argumentos
function suma(x, y)
{
    var resultado;
    resultado = x + y;
}
    Error: se supone que la función debe devolver un valor, pero no es así.
    Corrección: eliminar la variable resultado y colocar la instrucción return x + y; en la función, o agregar la siguiente instrucción al final del cuerpo de la función: return resultado; 
  3. function f( a );
{
    document.writeln( a );
}
    Error: el punto y coma después del paréntesis derecho que encierra la lista de parámetros.
    Corrección: elimine el punto y coma después del paréntesis derecho de la lista de parámetros.
